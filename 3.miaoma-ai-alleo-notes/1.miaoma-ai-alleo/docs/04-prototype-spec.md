# 原型设计说明

## 1. 原型目的

原型用于验证核心闭环是否容易理解，不用于提前确认视觉风格。测试重点是用户能否快速找到文档、调用 AI、检查引用、创建任务和完成协作。

可直接打开交互原型 [prototype/index.html](prototype/index.html)。

## 2. 页面清单

| 页面 | 入口 | 主要任务 |
|---|---|---|
| 工作区首页 | 登录后默认页 | 找到最近文档、任务和快速创建 |
| 文档编辑页 | 文档树或搜索 | 编辑、评论、调用 AI |
| AI 结果侧栏 | 编辑页 AI 按钮 | 选择动作、查看结果、打开引用 |
| 任务面板 | 首页或空间 | 查看、确认和完成任务 |
| 成员权限页 | 空间设置 | 邀请成员和调整文档权限 |
| 版本页 | 编辑页更多菜单 | 查看、对比和恢复版本 |

### AI 结果状态

```text
动作选择 → 生成中 → 结果预览 → 查看引用 → 采纳 / 插入 / 转任务 / 重试
```

结果卡片需要显式显示上下文范围、引用数量、生成时间和反馈入口。涉及任务创建的结果逐条提供确认勾选。

## 4. 关键交互

### 首次价值路径

用户打开默认项目空间，点击“新建会议纪要”，粘贴一段会议文本，点击“提取任务”，检查两条任务的引用，勾选其中一条并创建。完成后页面提示任务已进入项目列表。

### 引用回链

点击引用卡片后，AI 面板保留打开状态，编辑器滚动到原文块并短暂高亮。若用户没有权限或原文已删除，展示状态说明和文档标题，不显示敏感内容。

### 协作评论

用户选中一段文字后出现评论入口。发表评论时可以@成员。评论侧栏显示未解决数量，解决后保持可恢复。

## 6. 响应式和可访问性

桌面端优先，最低支持 1280 像素宽度。宽度小于 1024 像素时，文档树和 AI 侧栏改为抽屉。编辑器、评论和 AI 操作支持键盘访问，焦点状态清晰。颜色只用于辅助表达，在线、任务和权限状态同时提供文字。

## 7. 可用性测试任务

测试者不先看产品说明，依次完成以下任务。

1. 找到“项目周报”并打开。
2. 在文档中增加一段风险说明。
3. 让 AI 提取任务，并找出一条任务的来源。
4. 把一条任务分配给同事并设置截止日期。
5. 对一段文字发表评论并解决评论。
6. 找到昨天的版本并恢复。

记录完成时间、首次点击、错误路径、是否理解引用、是否知道任务已创建，以及测试者对 AI 结果的信任程度。
